# ST 分析与公告档案使用手册

## 页面

启动 TSP 后访问 `/st-analysis`。行情来自已同步的 enriched 日线，ST 按最新快照证券简称识别，涨跌停沿用系统原始价格规则。

5、10、20 个交易日榜各展示前 20 名，单位是小数收益率转百分比；计算为前复权收盘价除以 N 根日线之前的收盘价减 1。缺少窗口、空值和非有限值不参与排名，不以零代替。该口径按证券已有交易记录计数，停牌期间没有日线时不补造交易记录；盘中快照可能是未收盘值。

## 雪球日报导出

页面右上角“生成雪球日报”打开本地预览，固定打开时的行情和公告数据。可选择各榜前 5 / 10 / 20 名，文案包含情绪、涨跌停、涨幅榜及最多 10 条重要公告的标题与原文链接；行情日期、公告日期、采集时间和不完整/历史身份提示分别保留。没有有效行情时不生成日报，缺少涨跌幅时不把默认情绪分数当作有效判断。

文案可手动编辑后复制；改变榜单数量会重新生成文案。PNG 图片显示原始行情统计及三个榜单，手动编辑文案不会改变图片。下载后打开雪球，由用户粘贴文案、上传图片并审核发布。浏览器拒绝剪贴板权限时可在文案框中手动全选复制。

该功能只导出明确选择的公共行情与公告字段，不导出账号、token、策略配置或持仓；不保存雪球登录信息、不调用雪球发布接口、不自动发帖。无效窗口、不完整公告和不同日期不会静默伪装为完整同日数据。

## 公告采集与阅读

选择公告日期后，后端调用巨潮资讯当天全市场公告查询，不再靠关键词检索限定候选集；逐页采集、按公告 ID 去重，并核对总数。正常一次最多 4 个分页请求；失败页重试 2 次。每日 500 页是防失控上限，达到上限或数量不符明确显示不完整，不宣称全量完成。

默认展示重要公告（标题规则分类）；勾选“全部 ST 公告”展示包括普通会议通知等在内的全部 ST 公告。完整指巨潮查询当日返回的候选集，不保证源站未收录或撤回的披露。

点击刷新会强制重新采集。今天及昨天的完整档案缓存 15 分钟；更早的完整档案默认直接读本地。源站失败时保留并展示上次档案及采集时间，首次失败则显示错误。部分结果不覆盖已保存的完整结果。

点击“归档 PDF / 查看正文”下载附件、保存 SHA256 并提取文本；“本地 PDF”可在源站不可用时阅读已保存文件。PDF 限制 10 MB、正文解析最多 100 页、单页内容流 5 MB、总正文 50 万字。超限、损坏和扫描件分别标记，不把空正文视为成功。扫描件需要另行 OCR，本版本没有自动 OCR。机器提取文本不是投资建议或公告解读，关键事项需核对原文。

## 历史 ST 口径

历史日不能使用今天的名单倒推。证据优先级为：

1. 导入的核验证券简称生效区间（可包含 ST 和摘帽后的普通简称）。
2. 当天保存的证券名单快照。
3. 公告记录当时的证券简称，页面明确标记“公告时简称”。

当前证券维表只保存为今天的名单快照；不会伪造过去日期的快照。没有公告的证券不会凭公告简称被完整还原，因此这不是现成的全市场历史 ST 成分数据库，历史研究应导入核验区间。公告标题中的“拟撤销”“申请摘帽”不直接当作已生效。

页面“导入历史名单”接受 UTF-8 JSON：

```json
{
  "intervals": [
    {"symbol": "000001", "start": "2025-01-02", "end": "2025-06-03", "name": "*ST示例", "source": "交易所风险警示生效公告及原文链接"},
    {"symbol": "000001", "start": "2025-06-03", "end": null, "name": "示例股份", "source": "交易所撤销风险警示生效公告及原文链接"}
  ]
}
```

示例代码和日期仅演示结构。`start` 包含、`end` 不包含，必须填写真实生效日期及资料来源，同一股票区间不得重叠。普通简称区间用于明确排除已摘帽证券。相同代码与开始日期重新导入可修正原区间，整批校验和写入在事务中执行。导入后公告查询重新评估历史身份，不必再次下载全市场公告。

## 批量历史补采

在 backend 目录使用实际安装本项目依赖的 Python：

```powershell
uv sync --frozen --index-url https://pypi.tuna.tsinghua.edu.cn/simple
uv run --frozen python -m scripts.collect_st_announcements --start 2026-09-01 --end 2026-09-15
uv run --frozen python -m scripts.collect_st_announcements --start 2026-09-01 --end 2026-09-15 --membership .\st-history.json --pdf important
```

`--pdf all` 归档全部 ST 附件；`--refresh` 重新抓取已有日期。日期范围按自然日采集，周末也可能有公告。已保存完整日期和已成功提取的文件可复用，失败或不完整日期可以重跑恢复；存在采集/归档失败时退出码为 1。首次大量补采前确认存储空间，建议先从几天开始。本版本按页面请求或明确命令采集，不会自行创建定时任务，也未预先下载多年档案。

## 存储与接口

运行时数据保存在 `DATA_DIR/st_analysis/`：`archive.sqlite3` 保存每日全市场公告元数据、名单快照、核验区间与正文；`pdf/` 保存按 ID 哈希命名的原文。整个目录可备份迁移，不提交 Git。

- `GET /api/st-analysis/announcements?date=YYYY-MM-DD&include_all=true&refresh=false`
- `POST /api/st-analysis/membership/import`，JSON 请求体同上。
- `POST /api/st-analysis/documents/{id}?date=YYYY-MM-DD`，仅允许归档已采集 ID 的巨潮附件，不接受任意 URL。
- `GET /api/st-analysis/documents/{id}/pdf`，读取本地附件。

公告源在 `CninfoAnnouncementSource` 适配器内，业务采集可注入具有 `fetch_day(date) -> (rows, partial, pages)` 契约的替代源；不依赖 cfquant、AlphaQuant 日志或行情 SDK。价格榜依旧复用行情 provider 生成的 enriched 数据。公告相关查询键包含日期与全量筛选，强制刷新按原上下文写入缓存，历史导入只失效公告缓存，不清空行情和策略缓存。
